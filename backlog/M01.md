## Contexto
O repositório só tem `README.md` e o `.gitignore` de Rust. Não há código ainda.

## Tarefa
Montar o esqueleto do compilador em Rust, com um arquivo por fase, para que cada issue seguinte só precise preencher o seu módulo.

1. `cargo init --name monk` (lib + bin no mesmo crate). Edição 2021, dependência `clap` com a feature `derive`.
2. Criar `src/lib.rs` declarando `pub mod token; pub mod lexer; pub mod ast; pub mod parser; pub mod simbolos; pub mod semantica; pub mod ir; pub mod vm; pub mod otimizador;`. Cada módulo começa vazio (só um comentário dizendo qual issue o preenche, conforme o `CLAUDE.md`).
3. Criar as pastas `tests/`, `tests/casos/{validos,invalidos,semanticos}/`, `exemplos/`, `docs/` (use `.gitkeep` onde ficar vazio) e `tests/comum/mod.rs` vazio.
4. `src/main.rs`: CLI com `clap` que recebe `ARQUIVO`, lê o arquivo em UTF-8 e **só imprime o conteúdo**. Se o arquivo não existir, mensagem em stderr e código de saída 1.
5. CI em `.github/workflows/ci.yml`: em push e PR, rodar `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings` e `cargo test`.
6. README curto: objetivo do projeto e como compilar/rodar.

## Critérios de aceite
- [ ] `cargo build`, `cargo test`, `cargo fmt --check` e `cargo clippy --all-targets -- -D warnings` passam
- [ ] `cargo run -q -- README.md` imprime o README
- [ ] `cargo run -q -- nao_existe.mk` sai com código 1 e mensagem em stderr
- [ ] Todos os arquivos de módulo da seção 3 do `CLAUDE.md` existem
- [ ] CI verde no PR
