## Contexto
Nada depende de código aqui; pode ser feita em paralelo com {{M01}}. Se as pastas `docs/` e `exemplos/` ainda não existirem, crie-as.

## Tarefa
Fixar **o que a MiniLang aceita** antes de escrever o compilador. Esta especificação é congelada ao fim da issue.

1. `docs/especificacao.md` com todos os itens da proposta da aula 06:
   - tipos `int` e `bool` (literais `true`/`false`); `int` é inteiro de 64 bits com sinal
   - declaração `var nome: tipo = expr;` (sempre inicializada), atribuição `nome = expr;`, `print(expr);`
   - `if (c) { … } else { … }` e `while (c) { … }` — chaves obrigatórias
   - operadores em ordem crescente de precedência: comparação `== != < > <= >=` (não associativa) < `+ -` < `* /` < `-` unário
   - comentário `//` até o fim da linha; cada `{ }` abre um escopo
   - **decisão de sombreamento**: redeclarar no mesmo escopo é erro; declarar o mesmo nome em escopo interno é permitido
   - sem conversão implícita entre `int` e `bool`; `/` é divisão inteira truncando para zero; divisão por zero é erro de execução
   - seção "Extensões opcionais" (ex.: `&& || !`, `for`) marcada como fora do escopo obrigatório
2. `docs/gramatica.md`: rascunho em EBNF com uma regra por comando e para expressões (será refinado em {{M08}}).
3. Em `exemplos/`:
   - `fatorial.mk`: `var n: int = 5; var f: int = 1;`, o `while` do slide 3 da aula 06 e depois só `print(f);` (imprime `120`). É esta versão, sem o `if` final, que as aulas 26–30 usam como referência de TAC e de `--stats` (12 instruções, 40 executadas).
   - `if_else.mk` (pode ser o `if (f > 100)` do slide), `escopos.mk` (escopos aninhados com sombreamento)
   - dois inválidos com o erro descrito num comentário na 1ª linha
