## Contexto
O CLI ecoa o arquivo ({{M01}}) e o `Lexer` produz a lista de tokens ({{M04}}).

## Tarefa
Adicionar a flag `--tokens` em `src/main.rs` (clap). Com ela, o CLI roda o lexer e imprime um token por linha no formato:

```
2:1 VAR 'var'
2:5 ID 'n'
2:6 DOIS_PONTOS ':'
...
13:1 EOF ''
```

(`{linha}:{coluna} {TipoToken} '{lexema}'`). Sem a flag, o comportamento atual (ecoar) continua igual.

## Critérios de aceite
- [ ] `cargo run -q -- exemplos/fatorial.mk --tokens` imprime no formato acima
- [ ] Teste de integração em `tests/cli.rs` (rodando o binário com `std::process::Command` e `env!("CARGO_BIN_EXE_monk")`) conferindo a primeira e a última linha da saída
- [ ] Ajuda do clap (`--help`) descreve a flag
