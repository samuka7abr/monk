## Contexto
`ast::Tipo` existe ({{M10}}). `src/simbolos.rs` está vazio. A tabela é testada isolada, sem AST nem parser — pode ser feita em paralelo com o parser.

## Tarefa
Implementar `Simbolo`, `Categoria` e `TabelaSimbolos` conforme o contrato do `CLAUDE.md`, usando uma pilha de escopos `Vec<HashMap<String, Simbolo>>`:

- `new()` já cria o escopo global (nível 0)
- `entrar_escopo()` empilha; `sair_escopo()` desempilha (nunca remove o global)
- `declarar(nome, tipo, linha) -> bool`: `false` se o nome já existe **no escopo atual** (redeclaração); `nivel` = profundidade atual
- `buscar(nome)`: procura do topo para a base

## Critérios de aceite
- [ ] Teste `escopos`: declara `x: int`, entra, declara `x: bool` → `buscar("x")` dá `bool`; sai → dá `int`; declarar `x` de novo no global → `false`
- [ ] Teste de nome inexistente → `None`
- [ ] Teste de `nivel` correto em 3 níveis
- [ ] `cargo test --lib simbolos` passa
