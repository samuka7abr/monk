## Contexto
O frontend sintático está fechado e estável (tag `v0.2-checkpoint`, {{M15}}) e a `TabelaSimbolos` funciona isolada ({{M16}}). `src/semantica.rs` está vazio.

## Tarefa
1. `AnalisadorSemantico { tabela, erros }` com `new()` e `analisar(&mut self, prog: &mut Programa) -> Vec<String>`.
2. Travessia por `match` (o "Visitor" em Rust): métodos `visitar_comando`, `visitar_bloco`, `visitar_expr`, todos recebendo `&mut` (a {{M18}} vai anotar a AST).
   - `Bloco` (inclusive corpo de `if`/`while`): `entrar_escopo` → comandos → `sair_escopo`
   - `Decl`: **visitar a expressão antes de declarar** (em `var x: int = x + 1;` o `x` da direita ainda não existe); se `declarar` devolver `false` → `'{x}' já declarada neste escopo`
   - `Var` e `Atrib`: se `buscar` falhar → `'{x}' não foi declarada`
   - demais nós: só visitam os filhos
3. Mensagens no formato `linha {l}: erro semântico: {msg}`.
4. CLI: depois do parser, rodar o analisador; se houver erros, imprimir todos em stderr e sair com código 1. `--ast` só imprime a árvore se o programa for semanticamente válido.

## Critérios de aceite
- [ ] Teste `fora_do_escopo`: `{ var y: int = 1; } print(y);` → `["linha 1: erro semântico: 'y' não foi declarada"]`
- [ ] Teste `redeclaracao` no mesmo escopo e teste de sombreamento permitido em escopo interno
- [ ] Teste de `var x: int = x + 1;` sem `x` externo → erro
- [ ] Todos os testes anteriores passando
- [ ] `cargo test --lib semantica` passa

## Fora do escopo
Verificação de tipos ({{M18}}).

## Desafio opcional
Aviso (não erro) para variável declarada e nunca lida, como o `-Wunused-variable` do GCC.
