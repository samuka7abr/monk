## Contexto
O `AnalisadorSemantico` já percorre a AST com escopos e detecta redeclaração e uso não declarado ({{M17}}). `Expr.tipo` está sempre `None`.

## Tarefa
Completar o frontend: depois desta issue, toda AST que passa pela semântica é válida e tipada.

1. Tabela de regras `(OpBin, Tipo, Tipo) -> Tipo` (um `match` ou `HashMap`):
   - `+ - * /`: `int, int → int`
   - `< > <= >=`: `int, int → bool`
   - `== !=`: `int, int → bool` e `bool, bool → bool`
   - `-` unário: `int → int`
2. `visitar_expr` passa a devolver `Option<Tipo>`; `None` significa **"já reportei um erro aqui dentro"**. Se algum operando é `None`, devolve `None` **sem** reportar de novo (sem cascata).
3. Anotar: `expr.tipo = Some(t)` em toda expressão bem tipada.
4. Regras de comando:
   - `Decl`/`Atrib`: tipo da expressão = tipo da variável, senão `'{x}' é {tipo_var}, mas recebe {tipo_expr}`
   - `If`/`While`: condição `bool`, senão `condição deve ser bool, encontrado {t}`
   - operador inválido: `operador '{op}' inválido para {te} e {td}` (unário: `operador '-' inválido para {t}`)
5. Sem conversão implícita.
