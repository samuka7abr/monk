## Contexto
A VM executa TAC ({{M22}}) e o CLI já tem `--tac` com todas as fases do frontend ({{M21}}).

## Tarefa
1. Sem flags, `monk programa.mk` agora **compila e executa**: lexer → parser → semântica → TAC → VM. Cada fase só roda se a anterior não teve erro; qualquer erro → stderr e código 1 (inclusive `ErroExecucao`). O antigo modo "ecoar" deixa de existir.
2. `--stats`: depois da execução, imprime `[N instruções, M executadas]`, com N = `codigo.len()` (rótulos incluídos, como na aula 28) e M = `vm.executadas()`. Para o fatorial: `[12 instruções, 40 executadas]`.
3. Para cada programa válido de `exemplos/`, um arquivo `.out` com a saída esperada.
4. `tests/ponta_a_ponta.rs`:
   - helper `rodar(fonte) -> Vec<String>` em `tests/comum/mod.rs`
   - todos os `exemplos/*.mk` com `.out` produzem exatamente aquela saída
   - testes do binário (via `CARGO_BIN_EXE_monk`): código 0 no fatorial, código 1 em `erro_lexico.mk`, `erro_sintatico.mk`, `semantico.mk` e num programa com divisão por zero
5. README: seção "Executando programas". Depois do merge: tag `v0.4-vm`.

## Critérios de aceite
- [ ] `cargo run -q -- exemplos/fatorial.mk` imprime `120`
- [ ] `--stats` funcionando; números do fatorial anotados (são o "antes" de {{M26}})
- [ ] `cargo test --test ponta_a_ponta` passa
- [ ] Tag `v0.4-vm` publicada
