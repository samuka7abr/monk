## Contexto
O pipeline completo executa programas e mede instruções com `--stats` ({{M23}}). `src/otimizador.rs` está vazio.

## Tarefa
1. Contrato: `pub type Passe = fn(Vec<Instr>) -> (Vec<Instr>, bool)` e `pub const PASSES: &[Passe]`. `otimizar()` aplica todos os passes em sequência e repete **até nenhum mudar nada** (ponto fixo).
2. `dobrar_constantes`: `Bin`/`Neg` com operandos constantes vira `Copia` do resultado. Use a **mesma** função de avaliação da VM (extraia-a para uma função compartilhada, ex.: `ir::avaliar_bin`) para garantir a mesma semântica. **Nunca** dobre divisão por zero.
3. `propagar_constantes`: dicionário nome → constante conhecida; substitui usos por constantes. **Zera o dicionário em todo `Label`, `Goto` e `IfFalse`** (fronteira de bloco básico — no início de um `while` o valor pode ter vindo de dois lugares). Uma atribuição não constante a `x` remove `x` do dicionário.
4. Por enquanto `PASSES = [propagar_constantes, dobrar_constantes]`; os de limpeza entram em {{M25}}.
5. Flag `-O` no CLI: otimiza entre o gerador e a VM; combina com `--tac` (mostra o código otimizado) e `--stats`.

## Critérios de aceite
- [ ] Teste `dobramento`: `t1 = 2 * 3` → `t1 = 6`; `t = 1 / 0` **não** é dobrado
- [ ] Teste `propagacao`: `x = 5; t2 = x + 1` → `t2 = 5 + 1`; e propagação **não** atravessa um `Label`
- [ ] Teste `ponto_fixo`: `var base: int = 2 * 3 + 4;` vira `base = 10`
- [ ] Teste de que o fatorial otimizado continua imprimindo 120
- [ ] `cargo test --lib otimizador` passa
