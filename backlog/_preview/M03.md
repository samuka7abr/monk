## Contexto
O crate existe com `src/token.rs` vazio (#1) e a especificação está fechada em `docs/especificacao.md` (#2).

## Tarefa
Implementar `src/token.rs` exatamente como o contrato do `CLAUDE.md` (seção 4):

- `enum TipoToken` com todos os tokens da especificação (literais, identificador, reservadas, operadores, delimitadores e `Eof`), com `derive(Debug, Clone, Copy, PartialEq, Eq, Hash)`.
- `impl Display for TipoToken` imprimindo em SCREAMING_SNAKE (`DoisPontos` → `DOIS_PONTOS`, `MenorIgual` → `MENOR_IGUAL`). É o formato usado no `--tokens`.
- `struct Token { tipo, lexema: String, linha: usize, coluna: usize }` com `Debug, Clone, PartialEq`.
- `fn palavra_reservada(lexema: &str) -> Option<TipoToken>` cobrindo `var int bool true false if else while print` (um `match` basta).

## Critérios de aceite
- [ ] Todos os tokens da tabela da aula 08 existem
- [ ] Testes em `mod testes`: `palavra_reservada("while") == Some(While)`, `palavra_reservada("whilex") == None`, e o `Display` de pelo menos 3 tipos
- [ ] `cargo test --lib token` passa; clippy sem avisos
