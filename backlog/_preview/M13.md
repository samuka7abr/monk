## Contexto
O banco de casos existe em `tests/casos/` (#9) e `Parser::programa()` está completo (#12).

## Tarefa
1. Em `tests/comum/mod.rs`, helper `pub fn parse(fonte: &str) -> Result<Programa, ErroSintatico>` (lexer + parser). Os testes de integração seguintes reaproveitam este módulo com `mod comum;`.
2. Em `tests/casos.rs`:
   - `validos`: percorre `tests/casos/validos/*.mk` em ordem alfabética; todos devem parsear.
   - `invalidos`: para cada `tests/casos/invalidos/*.mk`, lê a 1ª linha, remove o prefixo `// ERRO: ` e verifica que `parse` falha com uma mensagem que **contém** esse texto.
   - Os testes acumulam as falhas e, no fim, fazem um único `assert!` listando **todos** os arquivos que falharam (não para no primeiro).
3. Se um diretório estiver vazio, o teste falha (evita passar sem testar nada).

## Critérios de aceite
- [ ] `cargo test --test casos` passa
- [ ] Quebrar de propósito uma mensagem no parser faz o teste falhar citando o arquivo

---
### Como saber que está pronta
`cargo test --test casos` passa

Ao terminar: `cargo fmt --check && cargo clippy --all-targets -- -D warnings && cargo test` sem falhas, PR com `Closes` desta issue e revisão de outro membro.
