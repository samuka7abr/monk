## Contexto
O parser devolve um `Programa` (#12) e o CLI já tem `--tokens` (#5).

## Tarefa
1. Em `src/ast.rs`, uma função `pub fn imprimir(prog: &Programa) -> String` que gera a AST **indentada, um nó por linha**:
```
Programa
├── Decl x: int
│   └── Num 1
└── Atrib x
    └── Binario +
        ├── Var x
        └── Binario *
            ├── Num 2
            └── Num 3
```
   Nomes dos nós: `Programa`, `Decl nome: tipo`, `Atrib nome`, `Print`, `If`, `Senao`, `While`, `Bloco`, `Unario -`, `Binario op`, `Num n`, `Bool b`, `Var nome`. Se `Expr.tipo` estiver preenchido, acrescente ` : int`/` : bool` (útil depois de #18).
2. Flag `--ast` no CLI: lexer → parser → imprime a árvore. Erro léxico continua saindo com código 1; erro sintático vai para stderr com código 1.

## Critérios de aceite
- [ ] Teste unitário comparando a saída de `var x: int = 1; x = x + 2 * 3;` com o texto acima
- [ ] `cargo run -q -- exemplos/fatorial.mk --ast` começa por `Programa`
- [ ] Erro sintático em `--ast` → stderr e código 1

---
### Como saber que está pronta
`cargo run -q -- exemplos/fatorial.mk --ast` imprime a AST indentada começando por `Programa`

Ao terminar: `cargo fmt --check && cargo clippy --all-targets -- -D warnings && cargo test` sem falhas, PR com `Closes` desta issue e revisão de outro membro.
