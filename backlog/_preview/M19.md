## Contexto
A semântica está completa e anotando a AST (#18); existe o helper `tests/comum/mod.rs` e o padrão de teste por arquivos (#13).

## Tarefa
1. Em `tests/casos/semanticos/`, um arquivo por caso inválido, 1ª linha `// ERRO: <mensagem>`:

| Conteúdo | Mensagem esperada |
|---|---|
| `var b: bool = 1 + 2;` | `'b' é bool, mas recebe int` |
| `x = 1;` | `'x' não foi declarada` |
| `if (1) { }` | `condição deve ser bool, encontrado int` |
| `print(true + 1);` | `operador '+' inválido para bool e int` |
| `var a: int = 1; var a: int = 2;` | `'a' já declarada neste escopo` |
| `{ var y: int = 1; } print(y);` | `'y' não foi declarada` |

   Acrescente pelo menos 2 casos próprios (ex.: `while (0) {}`, `var c: int = -true;`).
2. `tests/semanticos.rs`: mesmo esquema de #13, mas checando que algum item de `analisar()` contém a mensagem. Acrescente um teste que roda **todos os válidos** de `tests/casos/validos/` e exige `analisar() == []` (ajuste algum válido se ele tiver erro semântico).
3. `exemplos/semantico.mini` (o da aula 22). Conferir no CLI que os 3 erros saem em stderr, juntos, com código 1.
4. Atualizar o README (seção de erros). Depois do merge: tag `v0.3-semantica`.
