## Contexto
O frontend está completo: toda AST que chega aqui passou pela semântica e tem `Expr.tipo` preenchido (#18). O gerador **não precisa checar nada**. `src/ir.rs` está vazio.

## Tarefa
1. Tipos do contrato (`CLAUDE.md`, seção 4): `Valor`, `Operando`, `InstrKind`, `Instr`, com `Display` nos formatos:
   `  x = y` · `  t1 = a + b` · `  t1 = -a` · `  goto L1` · `  ifFalse t1 goto L2` · `L1:` · `  print a`
2. `GeradorTAC { codigo, nt, nl }` com `novo_temp()` (`t1, t2…`), `novo_rotulo()` (`L1, L2…`) e `emitir(kind, linha)`.
3. Expressões devolvem o **endereço** do resultado (`Operando`):
   - `Num`/`Bool` → `Operando::Const`; `Var` → `Operando::Nome`
   - `Binario`/`Unario` → visita os filhos em pós-ordem, emite e devolve um temporário novo
4. Comandos: `Decl`/`Atrib` → `Copia`; `Print` → `Print`; `Bloco` → comandos em sequência (escopos já foram resolvidos; nomes sombreados não são renomeados nesta issue — veja a observação).
5. Controle de fluxo (pedir os rótulos **nesta ordem** para a numeração bater com os testes):
   - `while`: `ini = novo_rotulo(); fim = novo_rotulo()` → `ini:` · cond · `ifFalse c goto fim` · corpo · `goto ini` · `fim:`
   - `if/else`: `senao = novo_rotulo(); fim = novo_rotulo()` → cond · `ifFalse c goto senao` · então · `goto fim` · `senao:` · senão (vazio se não houver `else`) · `fim:`

**Observação sobre sombreamento:** como a VM tem uma única memória, `var x` interno sombreando um `x` externo faria os dois colidirem. Resolva renomeando no gerador as variáveis declaradas em nível > 0 que sombreiam outra (ex.: `x` → `x_1`), usando uma pilha de escopos própria. Documente a escolha no topo de `ir.rs`.
